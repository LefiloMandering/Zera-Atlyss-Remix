# Atlyss Remix Mod GitHub Repository

Repository that contains the lua files, routes, and also the songs for Zera Atlyss Remix. Easier viewing than just downloading the zip in the site.

## Dependencies and Compatibility

This pack relies on and requires Marioalexsan's ModAudio Mod `v4.1.2` or higher, I cannot guarantee it may work on other versions of the mod.
The mod targets `ATLYSS 72025.a3` or higher.
The mod will likely stop working should there be any major updates.
If this mod does not work for whatever reason, don't blame me, blame Marioalexsan on BugAudio.
